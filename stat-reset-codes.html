What a Stat Refund is for

A refund lets you put points into a different build after the code is accepted. Confirm the exact message in game before changing your character plan.

Do not use several without checking

Redeem one code at a time and record the result. This separates an expired code from a character limit, a prior claim or a menu problem.

Codes are not a reset button

The reported codes grant refund items. They do not prove that every character or account can instantly reset its build through the same path.
