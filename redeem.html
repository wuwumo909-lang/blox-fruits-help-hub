How to Redeem Blox Fruits Codes

Quick answer

PC: open the settings or gear menu, find Redeem DLC Code, paste the exact code and confirm. Mobile: open the redeem menu or the gift box shown by your current interface, paste the code and confirm. A wiki page cannot redeem the code; it only explains where to enter it.

The exact icon can differ by game interface and device. Follow the path you can see in your current game screen.

PC

  1. Launch Blox Fruits in Roblox and choose Pirates or Marines.
  2. Open the gear/settings icon on the left side of the screen.
  3. Scroll to Redeem DLC Code or the redeem field.
  4. Paste the code exactly, then click Redeem!.

Mobile

  1. Open Blox Fruits in the Roblox mobile app.
  2. Look for the blue gift box or open the settings/cog menu.
  3. Open the redeem code field shown by your current interface.
  4. Paste the code, check the capitalization, then tap Redeem!.
Timing tip: activate a 2x EXP code just before a long quest or boss session so you do not waste the timer.
Redeem path note: the steps above are based on Fandom and IGN instructions plus Google result evidence; IGN was last updated October 26, 2026. The current site instructions are source-based; the redeem path still needs a real in-game screenshot before calling it verified.
